# Support

Choose the channel that matches your request so it reaches the right team.

## Public repository issues

For a reproducible bug or documentation problem in a public repository, open an issue in that repository. Include the affected version, environment, expected behavior, actual behavior, and a minimal reproduction. Remove credentials, personal data, customer information, and SAP connection details before posting.

## Security reports

Follow our [security policy](SECURITY.md) and report vulnerabilities privately. Do not use a public issue.

## Product and implementation support

- NeKu AI products, demos, and SAP Connector setup: [info@neku.ai](mailto:info@neku.ai) or the [NeKu AI contact page](https://neku.ai/en/contact/)
- NeKuDos consulting and corporate enquiries: [info@nekudos.com](mailto:info@nekudos.com) or the [NeKuDos contact page](https://nekudos.com/en/contact/)

GitHub issues are not a channel for sharing production credentials, confidential project details, or customer data.
