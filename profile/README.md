# NeKuDos Technology

Enterprise SAP engineering and governed AI integration.

NeKuDos Technology is a Türkiye-based software and consulting company focused on SAP, SAP BTP, enterprise automation, and governed AI. We build integrations that connect AI assistants and workflow systems to enterprise operations with explicit authorization, auditable execution, and human control where it matters.

## What we work on

- **[NeKu AI](https://neku.ai/en/)** — an enterprise AI platform for governed automation and SAP-connected workflows.
- **[SAP MCP Server](https://neku.ai/en/sap-mcp/)** — a controlled Model Context Protocol layer for exposing approved SAP capabilities to AI assistants.
- **[SAP Fiori Chatbot](https://neku.ai/en/sap-fiori-chatbot/)** — conversational access to SAP Fiori processes and enterprise information.
- **[n8n SAP Connector](https://neku.ai/en/n8n-sap-connector/)** — an n8n community node for SAP integration through the NeKu AI OData connector.

## Engineering principles

- Authorization is enforced at execution time, not inferred from tool visibility.
- State-changing operations should be explicit, reviewable, and auditable.
- Credentials, tokens, and customer data must not appear in source code, examples, issues, or logs.
- Integrations should follow least-privilege access and preserve the controls of the underlying SAP system.
- Documentation should describe both capabilities and operational boundaries.
